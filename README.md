# Улей — UX-кейс бронирования коворкинга

Лендинг и сценарий брони места за 30 секунд: тариф, дата и время, интерактивная карта мест с фильтрами, контакты с маской телефона и промокодом, подтверждение с QR. Desktop и mobile.

**Кейс:** https://condrusarsen.github.io/coworking-case/ · **Прототип:** https://condrusarsen.github.io/coworking-case/app.html

Сделано с ИИ: прототип собран ИИ-агентом (Claude Code) в рабочем процессе Арсения Атрохова. «Улей» — вымышленный коворкинг.
